## **Портфолио:** анализ данных и машинное обучение
Две лабораторные работы по анализу данных на Python. Каждая демонстрирует полный цикл работы: от очистки данных и EDA до интерпретации моделей и бизнес-выводов.


## Проект 1. RFM-анализ и кластеризация клиентов 
**Данные:** транзакции интернет-магазина подарков (541 909 записей, ~1 год).

### Содержание:

- **Очистка данных:** пропуски, дубликаты, возвраты, служебные записи (доставка, комиссии).

- **RFM-сегментация:** 3 уровня по каждому показателю → 27 сегментов на основе терцилей.

- **Сравнение методов кластеризации:** KMeans, DBSCAN, Agglomerative с обоснованием выбора.

- **Профилирование кластеров по категориям параметров:** ценовые, временные, количественные, скидочные.

- Детализация кластера «Середняки» на подгруппы для точечных стратегий.

- Бизнес-рекомендации для каждого сегмента.

**Методы:** EDA, очистка данных, RFM, K-Means, DBSCAN, иерархическая кластеризация, Cramér's V, радарная диаграмма, тепловые карты.

**Библиотеки:** `pandas`, `numpy`, `scikit-learn`, `scipy`, `seaborn`, `matplotlib`.

**Навыки**: работа с транзакционными данными, сегментация клиентов, интерпретация кластеров, бизнес-аналитика.

**Файл:** RFM_analis.ipynb

## Проект 2. Прогнозирование оттока клиентов (Churn Prediction)
Данные: банковские клиенты (10 000 записей, дисбаланс классов ~80/20).

### Содержание:

- **EDA**: распределения, boxplot, корреляции, тесты значимости (Манна-Уитни, Краскела-Уоллиса, хи-квадрат с поправкой Бонферрони).

- **Борьба с дисбалансом:** SMOTE, undersampling, взвешивание классов.

- **Модели:** Logistic Regression, XGBoost, Random Forest, Decision Tree C&RT.

- Подбор гиперпараметров через GridSearchCV по F1, Recall, PR‑AUC.

- **Интерпретация моделей:** feature importance, SHAP, SHAP interaction values, LIME.

- **Анализ ошибок:** профили групп, margin (уверенность моделей), непараметрические тесты.

- **Ансамбли:** Soft Voting, Hard Voting, взвешенноне голосование.

**Методы:** классификация, дисбаланс классов, гиперпараметрическая оптимизация, SHAP, LIME, ансамблирование, кластеризация, UMAP/t‑SNE, анализ ошибок.

**Библиотеки:** `pandas`, `numpy`, `scikit-learn`, `xgboost`, `imbalanced-learn`, `shap`, `lime`, `umap-learn`, `scipy`, `seaborn`, `matplotlib`.

**Навыки**: бинарная классификация, работа с дисбалансом, интерпретация моделей, анализ ошибок, ансамбли, бизнес-рекомендации.

**Файл:** Сhurn_predict.ipynb
